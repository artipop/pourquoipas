# Лента

Карточка, взятая в работу, разворачивается в **ленту** — полосу экранов, по
которой едешь вбок. Каждый выполненный шаг дописывает справа свои: ход агента,
терминал в папке карточки, заметки, встроенный браузер на адрес, который
записала стадия. Лент столько, сколько карточек в работе.

Когда шаг заканчивается, лента сама перелетает на следующий экран. Если вы
в этот момент смотрели куда-то ещё, она не дёргает вас с места, а предлагает
«Дальше →».

## Как двигаться

Голую прокрутку лента себе не забирает: колесо и два пальца принадлежат тому,
что под курсором, — странице в браузере, потоку агента, терминалу. Вбок
из них никто не прокручивается, поэтому два пальца вбок доезжают до самой полосы
и ведут её между экранами. Исключение — встроенный браузер: там жест забирает
себе страница.

Всё остальное — клавишами:

| | |
|---|---|
| `←` `→` | между экранами ленты |
| `↑` `↓`, `Cmd`+колесо | между лентами |
| `R`, `F` | ширина экрана |
| `Esc` | из ленты во входящие |

Когда вы набираете в заметках, клавиши принадлежат тексту; те же стрелки
с модификатором продолжают водить ленту.
