## Что сейчас

Шаблон из доски делают два пункта, и оба копируют доску как шаблон
(`POST /boards/{id}/duplicate?asTemplate=true`). Копия — новая личная доска с
флагом шаблона: колонки, поля, виды и карточки без комментариев, `properties`
доски целиком (промпт доски, вопросы настройки `setup`, отметка встроенного
шаблона, которую приложение снимает при следующем запуске, `disownTemplate`).

| | «Новый шаблон из доски» | «Сохранить как шаблон…» |
|---|---|---|
| Где | ⋯ доски в боковой панели (`sidebarBoardItem.tsx`) | ⋯ в шапке доски (`viewHeaderActionsMenu.tsx`), спрятан: `OFFER_SAVE_AS_TEMPLATE = false` |
| Имя копии | «New board template», всегда по-английски — так называет хранилище (`duplicateBoard`, `todo: server localization`) | имя доски |
| Что потом | открывается копия как доска, с баннером «Вы редактируете шаблон» | открывается окно «Шаблон» с вопросами настройки |
| Вопросы настройки | копируются с `properties` | записываются в копию ещё раз (`boardAutomationProperties`) — ничего не меняет, они уже там |

Комментарий в `saveAsTemplate.ts` о том, что без этого кода вопросы потерялись
бы, устарел.

## Предложение

Оставить один пункт — «Новый шаблон из доски» в боковой панели, — но с
поведением «Сохранить как шаблон…»: копия получает имя доски, после создания
открывается окно «Шаблон». Спрятанный пункт в шапке и лишнюю запись вопросов
настройки удалить. Обновить [templates.md](templates.md) и руководство
(`docs/guide/board.md`, ru и en).
