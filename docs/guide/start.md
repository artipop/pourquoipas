# Первый запуск

Эта страница о том, что приложение показывает на новой доске: последний шаг
настройки, первую задачу, тур по доске и подсказки.

## Последний шаг настройки

Новая доска открывается с мастером настройки: название и агент. Папку мастер не
спрашивает — её выбирают в карточке, в поле «Папка» (см. [«Папки и
ветки»](./folders.md)). На последнем шаге, **«Готово»**, есть три действия.

- **«Поставить первую задачу»**. Напишите в поле **«Первая задача, одним
  предложением»**, что нужно сделать, и нажмите кнопку. Приложение создаст
  карточку в первой колонке, назначит её агенту, перенесёт во вторую колонку и
  откроет. Перенос запускает агента — так же, как если бы вы перетащили карточку
  сами (см. [«Как доска запускает агента»](./automation/index.md)). Если агентов
  несколько, под полем есть выбор агента. Агент работает под вашей учётной
  записью у своего провайдера и расходует её лимит.

  Поле есть, только если на машине зарегистрирован агент, ИИ включён, а на доске
  есть две колонки и поле «кто занимается». Иначе вместо него есть кнопка
  **«Открыть «С чего начать»»**: эта карточка есть на каждой доске из шаблона и
  объясняет, как с доской работать.
- **«Показать, как устроена доска»** — закрывает мастер и начинает тур по этой
  доске.
- **«Готово»** — просто закрывает мастер.

Пройти мастер заново можно из меню доски: **«Пройти настройку заново…»**.

## Пока агент работает над первой карточкой

Пока агент работает над первой карточкой, под шапкой доски видна полоса: где
появятся вопросы агента, где смотреть результат и что агент сам перенесёт
карточку в колонку, название которой говорит, чем всё кончилось. На машине
одного человека результат — в папке и по кнопке **«Изменения»** на карточке; на
сервере — ещё и в комментарии. Полоса пропадает, когда карточка
уходит из колонки или агент заканчивает, и больше не появляется. Убрать её
раньше — кнопка **«Закрыть»**.

## Тур по доске

Тур — несколько подсказок поверх настоящих элементов доски, по порядку:

1. карточка — откройте любую;
2. в карточке — поле «кто занимается», папка, описание (это и есть задача);
   на сервере ещё комментарии;
3. на доске — колонки, **«Создать»** → **«Обсудить с агентом…»**, меню доски
   **«⋯»**, виды и ссылка на карточку; на сервере ещё кнопка
   «Поделиться»;
4. в списке слева — **«Входящие»**, список досок, поиск.

Кнопка **«Следующий»** ведёт дальше, **«Готово»** закрывает часть тура, крестик
пропускает её. Когда ИИ выключен, подсказок про агентов в туре нет.

## Подсказки

Некоторые вещи тур показать не может, потому что они случаются позже. О них
приложение говорит один раз, когда это происходит:

- агент впервые задал вопрос — подсказка у жёлтого значка на карточке;
- агент впервые сам перенёс карточку — подсказка на этой карточке;
- во «Входящих» впервые есть карточка — подсказка на ней;
- на карточке впервые появилась кнопка **«Изменения»** — подсказка у кнопки.

Одновременно видна одна подсказка. **«Понятно»** убирает её насовсем.

## Показать тур ещё раз

**«Настройки»** → **«Приложение»** → **«Тур по доске»** → **«Показать»**.
Тур начнётся на открытой доске, а скрытые подсказки снова появятся, когда
случится то, о чём они. Если ни одна доска не открыта, кнопка недоступна.
