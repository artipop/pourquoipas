# Компьютер и сервер: что где работает

Pourquoi Pas? ставится двумя способами:

- **на компьютер** — приложение с окном. В нём работает один человек, входить не
  нужно;
- **на сервер** — его открывают в браузере. У каждого свой вход и свои доски, а
  первый зарегистрировавшийся — администратор ([«Свой сервер»](./settings/team.md)).

Приложение на компьютере можно ещё **подключить к серверу**: доски тогда на
сервере, а агенты и папки остаются на компьютере. С телефона открывают сервер.

Совместной работы над одной доской нет: у доски один владелец.

## Агенты

| | Компьютер | Сервер в браузере |
|---|---|---|
| Агент-программа (Claude, Codex и другие по ACP) | есть | нет |
| Модель по ключу (Anthropic, OpenAI и совместимые) | есть | есть |
| Папки, ветки, кнопка «Изменения», поле «Папка» | есть | нет |
| Файлы и команды у модели | в копии карточки | нет: модель пишет результат на карточку |
| «Обсудить с агентом» | есть | есть |
| Разбор «Входящих» агентом | есть | есть |
| Прокси для агентов | есть | нет |

Агентов подключают в **«Настройки → ИИ»** ([«Подключение
агентов»](./settings/ai.md)); в браузере на сервере форма предлагает только
модели по ключу. Ключи и агенты — ваши: на сервере их не видят другие люди, и
любого своего агента можно назначить на любой своей доске.

Компьютер, подключённый к серверу, работает карточки сервера своими агентами:
программами, моделями и папками этого компьютера.

## Вопросы агента и уведомления

| | Компьютер | Сервер в браузере | Телефон |
|---|---|---|---|
| Вопрос на карточке, янтарный значок | есть | есть | — |
| Уведомления в окне доски | есть | есть | — |
| Уведомления системы, значок рядом с часами | есть | нет | — |
| Экран «Ждут» | — | — | есть |

Ответ из любого места закрывает вопрос везде.

## Остальное

| | Компьютер | Сервер в браузере |
|---|---|---|
| Вход по имени и паролю | нет | есть |
| «Поделиться» | нет | есть |
| «Входящие» | свои | одни на всех вошедших |
| Источники «Входящих» | есть | есть |
| «Поделиться» из системного меню (macOS) | есть | нет |
| «Настройки → Обновления» | есть | нет |
| «Настройки → Сервер» (подключиться) | есть | нет |
| «Настройки → Люди» | нет | только администратор |

Тема, язык, последняя открытая доска — ваши: на сервере у каждого свои и
переезжают с вами на другое устройство. Переключатель «Агенты работают с
карточками» — один на установку: на компьютере его меняете вы, на сервере —
администратор.

Деплоя нет ни там, ни там.
