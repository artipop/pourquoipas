# Темы

Тема выбирается в «Настройки → Приложение → Тема». Это выпадающий список, и
выбор применяется сразу — доска перекрашивается под ним.

## Что в списке

- **«Как в системе»** — светлая или тёмная тема XCIII, смотря как настроена
  система. Меняется вслед за ней, без перезапуска.
- **XCIII** — «XCIII — бумага» и «XCIII — экран», две темы, в которых
  нарисован сам продукт.
- **Портированные** — темы из списка сообщества Mattermost: Windows Dark, One
  Dark, Gruvbox Dark, Night Owl, Discord Dark, Solarized Dark, GitHub, Monokai.
- **Кислотные** — «Кислота: синий по жёлтому», «Кислота: жёлтый по синему»,
  «Эйсид-техно: лайм», «Эйсид-техно: фосфор».
- **«Свой конфиг»** — тема, которую вы вставили сами, см. ниже.

Выбранная тема хранится самой установкой: она переживает перезапуск и
действует на телефоне через [«Доступ с телефона»](./index.md#доступ-с-телефона).

## Свой конфиг

Тема — это объект JSON в формате Mattermost. Выберите в списке «Свой конфиг» —
под ним появится поле. Оно открывается копией той темы, которая была на экране,
так что новую тему проще всего написать, поправив старую. Вставьте свой конфиг
и нажмите **«Применить»**.

Готовые темы для этого формата лежат в документации Mattermost, в разделе
[Customize your theme](https://docs.mattermost.com/end-user-guide/preferences/customize-your-theme.html) —
их можно копировать оттуда целиком.

Минимальная тема — четыре ключа:

```json
{
  "centerChannelBg": "#1a1024",
  "centerChannelColor": "#ece0f7",
  "sidebarBg": "#2d1b4e",
  "buttonBg": "#a463f2"
}
```

Без любого из них тему не собрать, и поле скажет, какого ключа не хватает.
Всё остальное необязательно: чего конфиг не сказал, приложение выведет из того,
что сказано.

## Ключи

Цвета пишутся как `#1c1a16` (короткая запись `#abc` тоже понимается).

| ключ | что красит |
| --- | --- |
| `centerChannelBg` | фон доски |
| `centerChannelColor` | цвет текста |
| `sidebarBg` | фон левого списка |
| `sidebarText` | текст в левом списке |
| `buttonBg` | кнопки и акценты |
| `buttonColor` | текст на кнопке |
| `linkColor` | ссылки |
| `sidebarTextActiveBorder` | полоса у открытой доски |
| `errorTextColor` | ошибки |
| `dndIndicator` | точка «не беспокоить» |
| `awayIndicator` | предупреждения, «агент ждёт» |
| `onlineIndicator` | «прошло», «готово» |
| `mentionHighlightLink` | посещённые ссылки |

Остальные маттермостовские ключи (`sidebarHeaderBg`, `mentionBg`, `codeTheme` и
прочие) можно оставить в конфиге: приложение их сохраняет, чтобы тему можно было
вставить обратно в Mattermost, но само по ним ничего не рисует. Исключение —
`sidebarTeamBarBg` и `sidebarHeaderBg`: они используются, если `sidebarBg`
совпадает с `centerChannelBg`, чтобы у левого списка всё-таки была граница.

Сверх маттермостовских понимаются свои ключи:

| ключ | что красит |
| --- | --- |
| `name` | как тема названа в списке |
| `type` | `light` или `dark`; без него определяется по светлоте фона |
| `surfaceBg` | карточки и диалоги |
| `visitedLinkColor` | посещённые ссылки |
| `shadowColor` | тени и затемнение под диалогом |
| `labelDefault`, `labelGray`, `labelBrown`, `labelOrange`, `labelYellow`, `labelGreen`, `labelBlue`, `labelPurple`, `labelPink`, `labelRed` | десять цветов меток: колонки, приоритеты, любые списочные свойства |

## Что приложение поправит само

Цвета в теме для мессенджера рассчитаны на другие размеры: `awayIndicator` там
— точка рядом с именем, здесь — слово на карточке. Поэтому цвет, который на
фоне доски не читается, приложение затемнит или осветлит — ровно настолько,
чтобы текст стал читаемым, и не сходя с его собственного тона. То же с текстом
на кнопке: если он на ней не читается, приложение возьмёт тот, который читается.

Чего в конфиге нет — выводится: цвет карточки из цвета доски, десять цветов
меток из цвета карточки, тени из `shadowColor` или из цвета текста.

Тема, которая и так читается, не правится ничем.

## Если конфиг не приняли

Поле скажет, что с ним не так:

- «Поле пустое» — вставить нечего;
- «Это не JSON» — текст не разобрался; чаще всего пропущена запятая или кавычка;
- «Тема — это один объект JSON с цветами» — вставлен список или что-то другое;
- «Не хватает ключей…» — перечислены те из четырёх обязательных, которых нет;
- «Это не цвета вида #1c1a16…» — перечислены ключи с непонятным значением.

Тема при этом не применяется, а текст остаётся в поле — его можно поправить и
нажать «Применить» ещё раз.

## Терминал

Окно терминала остаётся тёмным при любой теме: там работает настоящий CLI, и
консоль на светлом фоне читается хуже. Тема красит обвязку вокруг терминала, но
не само полотно.
