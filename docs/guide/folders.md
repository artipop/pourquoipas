# Папки и ветки

Агент всегда работает в какой-то папке на вашей машине. Карточка выбирает одну
папку полем «Папка».

## Папка в карточке

Папку выбирают в самой карточке: нажмите на значение поля «Папка». В списке —
папки этой доски, под ними **«Добавить папку…»** и, если папка уже выбрана,
**«Без папки»**.

**«Добавить папку…»** открывает выбор папки на диске. Выбранная папка
добавляется на доску под своим именем и сразу ставится в карточку. Дальше она
есть в списке у всех карточек этой доски — второй раз добавлять не нужно. Если
эта папка уже добавлена на другой доске, приложение не заводит её заново, а
делает общей. Если имя уже занято другой папкой, к нему добавляется номер:
`app 2`.

На доске, где поля «Папка» ещё нет, в карточке всё равно есть строка «Папка» со
значением **«Не выбрана»**; первая добавленная папка создаёт поле.

Полный список папок, их переименование и настройки — в меню доски →
**«Папки…»**.

Если папка на доске всего одна, новая карточка получает её сразу: выбирать не
из чего, а поле заполнено и его видно. Когда папок несколько, поле остаётся
пустым — этот выбор за вами.

Папка карточки видна на её лицевой стороне на доске — строкой со значком папки
под названием. Если поле пустое, строки нет. «Черновики доски» там никогда не
показываются: это место, где работает карточка, которая папку не назвала, а не
ответ карточки.

**После начала работы папку сменить нельзя.** Как только агент начал работу
по карточке, поле становится нередактируемым и под ним написано, в какой папке
карточка работает. Сменить папку — значит завести новую карточку: работа
осталась там, где начиналась, и перенос поля её туда не перенесёт.

**Без папки агент всё равно запустится** — в черновиках доски, в отдельном
каталоге этой карточки. Каталог остаётся после работы: там лежит то, что агент
написал. Кода там нет и ветки нет, поэтому для карточки, по которой нужен код,
выберите папку. Если в поле выбрана папка, которую потом убрали из списка,
агент не запустится, а карточка скажет почему: выберите другую папку или
**«Без папки»**.

«Папки…» есть в меню каждой доски, на которой работают агенты.

Каждая папка в списке — название и под ним путь.

Папка бывает двух родов:

- **обычная папка** — заметки, тексты, списки. Агент работает прямо в ней, по
  одной карточке за раз; в списке она отмечена только своим названием;
- **репозиторий** — каталог под git, помечен словом **«репозиторий»**. Здесь
  агент работает в отдельной копии репозитория, на ветке этой карточки:
  несколько карточек идут одновременно, а ваш рабочий каталог не трогается.

Род не записывается раз и навсегда: приложение спрашивает git каждый раз, когда
показывает список. Сделали `git init` в папке, добавленной месяц назад, — она
стала репозиторием, ничего перенастраивать не нужно.

Добавляется папка одной кнопкой **«Добавить папку…»**, и репозитории стоят в том
же списке, что обычные папки, — и там, где «Обсудить с агентом» спрашивает
«В какой папке агенту читать?», тоже.

## Ветка карточки

Одна карточка — одна ветка, сколько бы раз по ней ни запускался агент. Ветка
отходит от главной ветки репозитория, копия лежит в данных приложения. Когда
работа закончена и всё закоммичено, копия убирается, а ветка остаётся:
следующий запуск по этой карточке восстановит копию из ветки. Копию с
несохранёнными изменениями приложение не трогает.

## Где работает агент

Агент работает в ветке карточки. Разговор без карточки
(«Обсудить с агентом») тоже стоит в самой папке и ничего в ней не меняет.
