# Проверить глазами

Сценарии, которые тесты и проверка без окна не закрывают: их надо пройти
руками в приложении. Пройденный сценарий удаляется отсюда; найденная ошибка
чинится или записывается как задача.

## Поле-ссылка на доске, которая не «Входящие», называется «Link»

Раньше на русской установке поле называлось «Ссылка». Его добавляет
`ensureLinkProperty` (`internal/boardadapter/writer.go`), когда карточка со
ссылкой приходит на доску без поля типа url. На «Входящих» оно переводится при
показе; на других досках остаётся «Link».

1. «Поделиться» из системы: создать доску из шаблона «Разработка», в Safari
   открыть страницу, «Поделиться» → Pourquoi Pas?, в окне выбрать эту доску, а
   не «Входящие», отправить. В карточке появилось поле «Link»
   (`sourcewriter.go`).
2. Разбор «Входящих» агентом (⋯ на «Входящих»): агент переносит карточку со
   ссылкой на доску без такого поля, и там появляется «Link» (`inboxsort.go`).

Решить по итогам: оставить «Link» или называть поле на языке страницы. У
«Поделиться» страница есть и может передать язык; у агента страницы нет.
