# site

Сайт Pourquoi Pas?: лендинг в корне и руководство пользователя под `/docs/`,
по-английски; по-русски то же под `/ru/`. Astro, руководство — Starlight; его
тексты лежат в `../docs/guide`, тексты лендинга — в `src/i18n/landing.ts`. Как всё
устроено и как добавить страницу руководства — [`docs/guide-site.md`](../docs/guide-site.md).

```
npm ci
npm run dev       # http://localhost:4321 — лендинг и руководство; работает в фоне,
                  # останавливается `npx astro dev stop`
npm run build     # dist/ — готовый сайт
npm run preview   # посмотреть собранное
```

`dist/` можно положить на любой статический хостинг. На GitHub Pages его
выкладывает `.github/workflows/pages.yml`.

## Что осталось вписать

- **почта** — `contactEmail` в `src/site.ts`. Пока её нет, в подвале нет адреса;
- **приём адресов** — `preorderEndpoint` в `src/site.ts`. Форма «Узнать о
  выходе» отправляет туда JSON (`email`, `name`, `os`); без адреса обработчика
  она открывает почтовую программу с письмом на `contactEmail`. Пока не задано
  ни то ни другое, формы и кнопки «Узнать о выходе» на странице нет;
- **цена подписки** — `price` в `src/i18n/landing.ts`: приложение
  бесплатное, суммы за ИИ по подписке пока нет.
