# site

Страница Pourquoi Pas?: как работает, Входящие, терминал и вопросы, факты о программе,
цена и форма «узнать о выходе». Статика — HTML, `styles.css`, `app.js` и шрифты; сборка
нужна, чтобы сложить их в `dist/` с хешами в именах.

```
npm ci
npm run dev        # http://localhost:5173 — страница и руководство вместе
npm run dev:site   # только страница, без руководства
npm run build      # dist/ — только страница
npm run build:all  # dist/ вместе с руководством в dist/docs
npm run preview    # посмотреть собранное
```

Страница собирается и выкладывается **сама по себе**: `dist/` — готовый сайт, его
можно положить на любой статический хостинг (Pages, S3, nginx). Вместе с
другими продуктами deffun её собирает проект `../../deffun` — он не читает
исходники, а запускает `npm run build` здесь и копирует `dist/`. Где страница
будет лежать, ему и остальным говорит переменная **`BASE`** (по умолчанию `/`,
в общей сборке `/pourquoipas/`); руководство всегда лежит в `BASE` + `docs/`. Поэтому
ссылки в HTML, которые Vite сам не переписывает, пишутся как `%BASE_URL%docs/`, а
не `/docs/`. Куда ведёт логотип «deffun», говорит `VITE_HOME_URL`: в одиночку
это сама страница (`.env`), в общей сборке — главная.

**Собирать надо `build:all`**: руководство — отдельный проект на VitePress
(`../docs/guide`), и `build:all` кладёт его сборку в `dist/docs`. Про сам
доксайт — [`docs/guide-site.md`](../docs/guide-site.md).

В деве руководство — отдельный сервер на 5174, а этот проксирует на него `/docs`
(`server.proxy` в `vite.config.js`, с `ws` — иначе горячая перезагрузка
руководства вечно «connecting»). `npm run dev` поднимает оба разом
(`concurrently`, и `-k` — чтобы `Ctrl-C` уносил обоих). Два процесса здесь —
цена VitePress: у него свой дев-сервер, и один порт он отдаёт одному сайту.

Главная страница deffun со списком продуктов здесь не лежит: она в проекте
`../../deffun`.

## Дизайн

Токены в начале `styles.css` — те же, что в `frontend/src/styles/_tokens.scss`:
тёмная тема — экран, светлая — бумага; машина говорит разрядкой в верхнем
регистре, человек — прозой. Тему выбирает встроенный скрипт в `<head>`, до
первой отрисовки: `app.js` — модуль и выполнился бы уже после неё. Шрифты
(`fonts/`) скопированы из `frontend/node_modules/@fontsource-variable`, только
latin и cyrillic.

`styles.css` и шрифты продублированы в `../../deffun`: главная страница
выглядит как продукты, но не зависит от их чекаутов. Карточки продуктов и
всё, что нужно только им, правятся там; сюда относится только то, что нужно
этой странице.

## Профили

Страница собирается для разных площадок: `PROFILE=org` (по умолчанию) или
`PROFILE=personal`, это режим Vite. Значения лежат в `.env.<профиль>` (название
в шапке и футере, домен для canonical), а блоки, которые различаются
(`<!--profile:имя-->` в `index.html`), — в `profiles/<профиль>/<имя>.html`;
без файла блок пустой. Значения `personal` пока пустые, там стоят `TODO`.
Руководство берёт имя в `© 2026` из `PROFILE_NAME`. Общая сборка —
`../../deffun`.
